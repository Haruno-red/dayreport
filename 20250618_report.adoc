= DockerコンテナにおけるLAMP環境の構築（続き）

== init.sqlファイルを流すためのスクリプト（test.sh）作成
test.sh内のソースコード ::
[source,bash]
----
#!/bin/bash

# 環境変数が設定されているか確認
if [ -z "$MYSQL_ROOT_PASSWORD" ] || [ -z "$MYSQL_USER" ] || [ -z "$MYSQL_PASSWORD" ] || [ -z "$MYSQL_DATABASE" ];
then
  echo "Error: 環境変数 MYSQL_ROOT_PASSWORD, MYSQL_USER, MYSQL_PASSWORD, MYSQL_DATABASE が設定されていません。"
  exit 1
fi

# MySQLに接続する
mysql --user=root --password=$MYSQL_ROOT_PASSWORD -e "CREATE DATABASE IF NOT EXISTS \`$MYSQL_DATABASE\`;"
if [ $? -eq 0 ];
then
  echo "データベース '$MYSQL_DATABASE' が正常に作成されました。"
else
  echo "データベース '$MYSQL_DATABASE' の作成に失敗しました。"
fi
----

上記ソースコードの問題点 ::
* 処理の途中でエラーがあってもそのまま最後まで読み込んでしまう。 +
→ １行目に `-eu` というオプションを付けると良い。
+
[options="header"]
|======
|オプション　|意味
|-e　|実行中にエラーが出た時点で処理を終了する
|-u　|未定義の変数が使用されたときにエラーとなる
|======
* 環境変数が定義されているかのif文について、どの環境変数でエラーになるか明確でない。 +
→ 一つひとつ分けたif文で構成する。
* 関数を使用していない。
* if文の `then` が改行してしまっている。 +
※関数の文法をチェックしてくれるフォーマットツールを入れると良い。
